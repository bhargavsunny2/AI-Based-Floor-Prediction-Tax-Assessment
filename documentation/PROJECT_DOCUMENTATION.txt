AI-BASED FLOOR PREDICTION AND TAX ASSESSMENT SYSTEM
====================================================

1. INTRODUCTION
---------------

The AI-Based Floor Prediction and Tax Assessment System is a
Python-based machine learning application designed to predict
the number of floors of a building and estimate property tax.

The system accepts property-related information such as plot
area, building height, road width and location score.

A Random Forest Classification model is used for floor
prediction. After prediction, the system estimates property
tax using a predefined calculation method.

The application provides a graphical user interface using
Tkinter and stores assessment records using SQLite.


2. OBJECTIVES
-------------

The main objectives of the project are:

1. To predict the number of building floors using Machine
   Learning.

2. To estimate property tax automatically.

3. To provide a simple graphical user interface.

4. To store assessment information in a database.

5. To provide assessment history.

6. To demonstrate the practical application of Artificial
   Intelligence and Machine Learning.

-----------------

The system uses four input features:

1. Plot Area

5. OUTPUT
---------

The system produces:

7. MACHINE LEARNING
-------------------

A Random Forest Classification model is used to predict the
number of floors.

The model is trained using property-related features:

- Plot area
- Building height
- Road width
- Location score

The trained model is saved using Joblib and loaded by the
Tkinter application during execution.


8. PROPERTY TAX ASSESSMENT
--------------------------

After the number of floors is predicted, the system calculates
an estimated property tax.

The calculation considers:

- Plot area
- Predicted number of floors
- Location score

The calculated amount is displayed to the user.


9. DATABASE
-----------

SQLite is used to store property assessment records.

Stored information includes:

- Plot area
- Building height
- Road width
- Location score
- Predicted floors
- Estimated property tax


10. GRAPHICAL USER INTERFACE
----------------------------

The Tkinter interface provides:

- Property input fields
- Assess Property button

- View History button
- Predicted floor result
- Estimated tax result
- Dashboard information


11. TESTING

13. LIMITATIONS
---------------

1. The dataset is small and intended for demonstration.
2. Tax calculation is simplified.
3. Location score is entered manually.
4. The system does not use live government zoning data.
5. Results are not official government building approval
   or official tax assessments.
